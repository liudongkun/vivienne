# Credits and publication scope

## Project lineage

The application prototype introduced here is based on:

- [OpenMuse Standalone](https://github.com/caspianchan31/openmuse-standalone), by Caspian Chan and contributors.
- [CopilotKit OpenMuse](https://github.com/CopilotKit/openmuse), now redirecting to OpenFuse, and its contributors.

The base application and engine contain upstream work. This showcase does not claim original authorship of the underlying Agent loop, worker or UI framework.

Yuki is a separate project by the Standalone author. Its presentation informed the layout of this introduction; its character artwork and additional implementation code are not included.

## Artwork

`assets/vivienne-poster.png` is AI-generated original character concept artwork created for this project with OpenAI image generation. `assets/vivienne-banner.png` is its landscape adaptation with the English tagline, used on the introduction pages. Both depict a fictional adult character and are not screenshots of the application or a real person.

The original portrait image is preserved. The landscape banner was recomposed and its typography edited with image generation. The name and artwork are a new visual identity for the existing personal prototype; their integration into the application remains ongoing.

## What is published

This repository contains introductory documentation and the character poster only. It contains no application implementation, runtime configuration, personal account data or credentials.

Publishing this showcase does not grant an application source-code license. Any future code publication will include the applicable upstream notices and licensing information.
